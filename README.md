# Lectern site

Home page, privacy policy and terms for **Lectern**, a self-hosted AI email desk built for a university professor.

**Live:** https://muhammadsabihulhussnain.github.io/lectern-site/

| File | What |
|---|---|
| `index.html` | Home page: what Lectern is, who can use it, contact |
| `privacy.html` | Privacy policy |
| `terms.html` | Terms of service |
| `style.css`, `icon.svg` | Styles and icon |

Plain HTML and CSS with no build step. To preview it locally:

```sh
python -m http.server 8080
```

Then open http://localhost:8080.
